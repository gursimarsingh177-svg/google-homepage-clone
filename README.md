# Google Homepage Clone

## Project Description

This project recreates the basic appearance of the Google homepage using HTML5 and CSS3. It was developed as part of the Week 1 One Month Mentorship Program assignment.

## Features

* Google-style logo and homepage layout
* Top navigation links
* Rounded search input field
* Search buttons for visual demonstration
* Footer links
* Responsive design for desktop and mobile screens
* Keyboard accessibility with visible focus indicators

## Technologies Used

* HTML5
* CSS3

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser such as Google Chrome.

## Important Note

This is an educational UI clone only. The search field and buttons do not perform real Google searches.
